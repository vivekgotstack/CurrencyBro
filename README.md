# <img src="https://upload.wikimedia.org/wikipedia/commons/7/72/Indian_Rupee_symbol.svg" alt="RS Logo" width="50" /> Currency Converter

A modern, lightweight **Currency Converter** built with **React**, **TypeScript**, and **Tailwind CSS** using **ShadCN components**. Convert currencies in real-time with an elegant glassmorphic UI.

## Features

- Convert between any two currencies using live exchange rates.
- Glassy, blurred background with a clean input design.
- Gradient Swap button with smooth hover and loading spinner.
- Responsive and mobile-friendly.
- Minimalistic and user-friendly interface.

## Tech Stack

- React + TypeScript  
- Tailwind CSS  
- ShadCN UI components  
- Fetch API for currency rates  

## Usage

1. Clone the repository:  
   ```bash
   git clone <repo-url>
   cd currency-converter
   ```

2. Install dependencies:  
   ```bash
   npm install
   ```
   
3. Run the project:  
   ```bash
   npm run dev
   ```
